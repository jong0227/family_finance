# 기능 정의와 제안 시나리오

> 공개 저장소 문서입니다. 실명·계좌번호·실제 금액은 쓰지 않습니다(예시는 가짜 숫자).
> 등장인물: **나**(주 사용자, 데이터 올림), **배우자**(같은 화면을 실시간으로 봄), 아이 2명.

## 0. 이 앱이 풀려는 문제
- 가계 계획(엑셀)은 있지만 **실제 지출과 연결이 안 돼** 계획이 지켜지는지 모른다.
- 카드·통장이 여러 개라 **어느 카드에 무엇이 붙어 있고, 결제일에 어느 통장에서 얼마가 빠지는지** 머릿속에만 있다.
- 뱅크샐러드 분류는 우리 집 기준과 다르고, 쿠팡 결제는 한 줄로 뭉쳐 **무엇을 샀는지** 보이지 않는다.
- 부부가 같은 숫자를 보지 못해 대화가 "대충 많이 쓴 것 같다"에서 멈춘다.

## 1. 핵심 기능 (요청 사항)
| # | 기능 | 한 줄 정의 | 완료 기준 |
|---|---|---|---|
| F1 | 월별 지출 추적 | 이번 달·지난달·최근 12개월 지출을 계획과 함께 본다 | 홈에서 이번 달 계획 대비 실제와 남은 예산이 3초 안에 보인다 |
| F2 | 항목별 월 추이 | 지출 분류·항목마다 월별 막대 + 계획선, 그 안의 거래 목록 | 아무 항목을 눌러 12개월 추이와 많이 쓴 곳 Top 5가 보인다 |
| F3 | 줄일 것 / 여유 있는 것 | 계획 대비 초과·절감 항목을 순위로 보여 주고 이유(많이 쓴 곳)를 붙인다 | 초과 상위 3개와 여유 상위 3개가 금액·원인과 함께 나온다 |
| F4 | 카드·통장 지도 | 카드별로 붙어 있는 정기결제·고정지출, 그 카드 대금이 빠지는 통장, 결제일 | 카드를 누르면 연결 항목·월 합계·출금 통장·다음 결제일이 보인다 |
| F5 | 부부 실시간 공유 | 초대 코드로 가족을 연결해 같은 데이터를 본다 | 한쪽에서 고치면 다른 폰에 몇 초 안에 반영 |
| F6 | 뱅크샐러드 가져오기 | 내보낸 엑셀을 올리면 새 거래만 추가·분류, 애매한 건 확인 질문 | 같은 파일을 두 번 올려도 중복 0건, 되돌리기 가능 |
| F7 | 쿠팡 캡처 매칭 | 주문내역 캡처를 글자인식해 쿠팡 결제를 상품 단위로 쪼갠다 | 결제 총액은 그대로, 못 맞춘 금액은 "내역 미확인"으로 남는다 |

## 2. 제안 기능 — 시나리오
각 시나리오는 "누가 · 언제 · 무엇을 보고 · 무엇을 결정하나"로 적었다. 우선순위: ★★★ 바로, ★★ 다음, ★ 나중.

### S1. 결제일 현금 점검 ★★★
- **누가/언제**: 나, 카드 결제일 3일 전 알림.
- **무엇을 보나**: 통장별로 "빠질 금액(카드대금 + 자동이체) vs 지금 잔액(직접 입력 또는 마지막 값)" → 모자란 통장과 금액.
- **결정**: 어느 통장으로 얼마를 옮길지. 결제일이 주말이면 다음 영업일로 자동 보정.
- **왜**: 매달 "카드값 얼마 모자라?"를 손으로 계산해 왔다. 마이너스통장 한도는 현금으로 치지 않고, 쓸 수 없는 돈(예: 다른 사람 돈을 모아 둔 통장)은 제외 표시를 할 수 있어야 한다.

### S2. 할부·정기 대형 지출 타임라인 ★★★
- **누가/언제**: 부부, 월초.
- **보나**: 남은 할부(몇 회차 남았나, 끝나면 월 얼마 여유), 연납·분기·3개월권(자동차보험, 방과후, 상담 등)의 다음 결제 예정.
- **결정**: 큰 지출이 몰리는 달을 미리 알고 그 전달에 아껴 둔다.

### S3. 정기결제 감시 ★★★
- **보나**: 새로 생긴 정기결제(같은 가맹점·비슷한 금액이 2개월 연속), 금액이 바뀐 구독, **해지했다고 기록했는데 다시 결제된 것**.
- **결정**: 해지·요금제 변경. 예) "OO 구독이 이번 달 9,900 → 13,900원으로 올랐어요".

### S4. 월말 점검 리포트 ★★
- **언제**: 매월 말일 또는 카드 결제일 다음 날.
- **보나**: 한 장 요약 — 계획 대비 실제, 줄일 것/여유, 쿠팡 미확인 비율, 다음 달 예정 대형 지출. PDF/이미지로 공유.
- **결정**: 다음 달 예산을 조정할지. 조정은 "계획" 화면에서 하고 이력이 남는다.

### S5. 확인 질문 큐 — 한 번에 하나 ★★★
- **언제**: 가져오기 후, 또는 틈날 때.
- **보나**: "11/12 OO클럽 100,000원(가나다카드) — 어느 항목인가요?" 근거(날짜·금액·카드·비슷한 과거 거래)와 선택지.
- **결정**: 답이 곧 분류 규칙이 되어 다음부터 자동 분류. 배우자도 답할 수 있고 누가 답했는지 남는다.

### S6. 대신 결제·정산 추적 ★★
- **보나**: 친구·친척 것을 대신 결제하고 돈을 받은 거래를 "소비 아님(정산)"으로 묶고, 아직 못 받은 금액을 표시.
- **결정**: 받을 돈 독촉. 소비 통계에서 자동 제외.

### S7. 아이별 지출 보기 ★★
- **보나**: 아이1비·아이2비 분류 + 쿠팡 상품명의 아동·유아 키워드로 아이별 월 지출과 추이.
- **결정**: 학원·용품 예산 조정.

### S8. 절감 시뮬레이터 ★
- **보나**: "외식을 월 10만 줄이면 1년에 120만 → 할부 조기 상환 시 이자 OO 절약" 같은 슬라이더.
- **결정**: 줄일 목표를 정하고 계획에 반영.

### S9. 거래에 부부 메모·태그 ★★
- **보나**: 거래 하나에 "이건 생일 선물", "환불 예정" 같은 메모와 태그. 상대방에게 알림.
- **결정**: 일회성 지출을 평소 지출과 구분.

### S10. 같은 가구와 비교 ★
- **보나**: 통계청 가계동향 항목별 평균과 우리 집 비교(가구원 수 기준 표시).
- **결정**: 유난히 높은 항목을 점검.

## 3. 데이터 원칙
1. **계획과 실제는 다른 층**: 계획(구분 → 지출 분류 → 항목, 월 금액)은 사용자가 정하고, 실제는 거래에서 계산한다. 계획을 실제에 맞춰 자동으로 바꾸지 않는다.
2. **분류 체계는 사용자 것**: 사용자의 기존 체계(대출/생활비/저축/변동 → 지출 분류 → 항목)를 그대로 쓰고, 앱이 임의로 합치거나 이름을 바꾸지 않는다.
3. **근거 우선순위**: 사용자가 올린 캡처·카드 앱 화면 > 카드/은행 기록 > 사용자 기억. 근거를 거래에 남긴다.
4. **되돌릴 수 있게**: 가져오기·일괄 분류는 묶음 단위로 되돌릴 수 있다.
5. **개인정보는 저장소에 없다**: 계좌번호·실명·금액·개인 규칙은 Firebase에만.
